// Projekt-Highlights

Alles was ein moderner Mini-Server braucht

Kompakt im Code, professionell in der Architektur & blitzschnell eingerichtet.

CustomTkinter GUI

Ansprechende, dunkle Desktop-Benutzeroberfläche basierend auf CustomTkinter mit flüssigen Animationen und intuitivem Dashboard.

System-Tray Integration

Dank PyStray verschwindet die App auf Wunsch sauber in die Windows Taskleiste oder macOS Menüleiste und läuft dort ressourcenschonend.

HTTP Core & IP Detection

Python-eigener multithreaded HTTP-Server. Erkennt automatisch die lokale WLAN/LAN IP-Adresse für schnelles Testen von Mobilgeräten.

PyInstaller & Batch Build

Mit dem mitgelieferten build.bat Skript lässt sich das Projekt im Handumdrehen in eine eigenständige `.exe` kompilieren.

Automatische GitHub CI/CD

Integrierte `.github/workflows/build.yml` baut automatisch bei jedem Push oder Release eine einsatzbereite Executable.

Pytest Unit & Smoke Tests

Umfassende Testabdeckung für Server-Threads, Pfad-Auflösung und Headless UI Smoke Tests stellen ständige Stabilität sicher.

// Modulares Design

Clean Architecture in Python

Das Projekt ist strikt in nachvollziehbare Module unterteilt. Kern-Logik, Benutzeroberfläche und Hilfs-Utilities sind sauber voneinander getrennt.

mini_webserver/core/ Enthält den multithreaded Server Wrapper.
mini_webserver/ui/ CustomTkinter App Window & Tray Manager.
mini_webserver/utils/ IP-Netzwerkerkennung & Pfad-Helfer.

Installations- & Build-Anleitung

Requirements: Python 3.9+ 
# 1. Repository klonen
git clone https://github.com/bosancero85/Pandora-Mini-Webserver.git
cd Pandora-Mini-Webserver

# 2. Abhängigkeiten installieren (CustomTkinter, PyStray, Pillow)
pip install -r requirements.txt

# 3. Mini Webserver starten
python main.py
# Windows-Programm lokal mit PyInstaller kompilieren
.\build.bat

# Die fertige .exe Datei befindet sich anschließend in:
dist/MiniWebserver.exe
# Linux-Programm lokal bauen (Python 3.9+, tkinter und venv nötig)
# Debian/Ubuntu/Kali/Raspberry Pi OS: sudo apt install python3-tk python3-venv
bash build_linux.sh

# Ergebnis (x86_64 oder arm64, je nach Rechner):
dist/MiniWebserver-Linux-x86_64.tar.gz
# macOS-App lokal bauen (Python 3.9+ mit tkinter, z. B. brew install python-tk)
bash build_macos.sh

# Ergebnis (arm64 oder x86_64, je nach Mac):
dist/MiniWebserver-macOS-arm64.zip
# Pytest & Smoke-Tests ausführen
pytest tests/ -v

# Output:
tests/test_core.py :: test_server_start_stop PASSED
tests/test_ui_smoke.py :: test_gui_initialization PASSED
